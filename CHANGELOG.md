## [0.1.0] - 2026-04-09

### Added
- Initial release of Academia.ai.
- Next.js 15 + React 19 application foundation with App Router.
- Supabase integration for authentication, database access, and realtime features.
- Role-based user flows for student and teacher dashboards.
- Course management and enrollment request workflows.
- Assignment creation, tracking, and submission flows.
- Exam management, student exam portal, and review experiences.
- Live class scheduling and join flows using Socket.IO and WebRTC signaling.
- AI chatbot workflow and Gemini-based answer evaluation integration.
- Landing, authentication, profile, support, and dashboard UI routes.

### Infrastructure
- Tailwind CSS v4 and ESLint setup.
- Socket client/server integration points for live communication.
- Project scripts for development, build, start, and lint.
